# Aktien-Radar

Relative Stärke nach Levy (RSL, 130 Tage) und 4-Wochen-Momentum für Aktien weltweit,
ETFs, Rohstoffe, Währungen und Krypto. Kursdaten: Yahoo Finance. Keine Anlageberatung.

- Seite: https://markuswetzel01.github.io/Aktien-Radar/
- Läuft automatisch jeden Montagmorgen; manuell über **Actions → Aktien-Radar → Run workflow**.
- Aktienliste anpassen: `tickers.csv` (Spalten `ticker,name,region,immer`).
- Lokal unter Windows: `start.bat` (liegt im Dropbox-Ordner, nicht hier).
